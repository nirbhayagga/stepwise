# Interactive Algorithm Visualizer

A premium, interactive web-based educational platform designed to dissect, explore, and visualize computer science algorithmic concepts in real-time. Driven by an immutable generator-trace timeline engine, the application computes memory footprint snapshots per operation, completely decoupling UI scaling limits from raw logic execution mapping.

## Core Features

1. **Analytical Data Engines**
* **Bi-Directional Time Travel:** Step backwards and forwards manually to view structural arrays trace-by-trace.
* **Pseudocode Synchronization:** Fully integrated logic panels follow `while` loop scopes seamlessly highlighting active variable evaluations.
* **Split-Screen Comparison:** Run O(N^2) against O(N log N) models head-to-head tracking comparative metric gaps locally.
* **Watch Windows:** Exposes specific raw numeric array states, tree rotations, node heuristics, and pivot swaps into readable values.

2. **Sorting Visualizers**
* **Algorithms:** Displays array items actively matching _Bubble Sort, Merge Sort, Quick Sort, Insertion Sort, and Selection Sort._
* Live variables panel records iteration matrices exactly corresponding array depth.

3. **Dynamic Programming Models**
* **Algorithms:** Solves complex memoization recursion tables for _0/1 Knapsack_ constraints and _Longest Common Subsequences_.

4. **Pathfinding & Graph Generators**
* **Algorithms:** Renders complete search wavefronts for heavily weighted terrains against _Dijkstra's Algorithm, A*, Greedy Best-First Search, Bidirectional BFS, standard BFS, and DFS_.
* **Interactive Tooling:** Features mouse-click `Draw Mode` mapping variables (`Wall` / `High-Cost Weight` states).
* **Recursion Generators:** Instantiate and auto-solve generated structures spanning Random Walls or pure `Recursive Backtracking Maze Generation`.

5. **Acyclic Tree Structures**
* **Algorithms:** Maps scalable SVG nodes against _Binary Search Tree_ recursive insertions, alongside complete self-balancing _AVL Trees_.

6. **Custom Web-Worker Sandbox**
* An interactive logic editor interface built directly into the UI safely wrapping execution environments for user-built algorithmic generators without halting the main Thread.

## Technology Stack

* **Vue 3 (Composition API):** Responsive component architecture.
* **TypeScript:** Strong structural generator interfaces maintaining UI state synchronicity.
* **Vite:** Blazing fast production compiler bundles.
* **Web Workers:** Sandbox protections for hostile infinite recursion algorithms.
